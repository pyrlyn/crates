# AGENTS.md

If an AGENTS.md or CLAUDE.md exists higher in the tree, follow it too; on conflict, ask the creator.

This crate owns completion generation from clap commands. Application-specific package lookup,
installation policies and terminal prompts stay in the applications. Preserve generated bytes
when moving code; test escaping, hidden arguments, aliases and all supported shells.

Run `cargo test -p shell-completions` and `cargo clippy -p shell-completions --all-targets -- -D warnings`.
