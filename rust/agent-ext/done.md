# agent-ext — completed tasks

### T1. Extract skills and shell hooks from cox-ext

Moved out of cox's `crates/cox-ext` (`skills.rs`, `hooks.rs`, `frontmatter.rs`; aulo task T1.17). Skills: `SKILL.md` discovery with later directories overriding earlier ones, the `# Skills` index line, and the deferred `skill` tool as a host-neutral `SkillTool` (`spec`, `subject`, `call`). `skill_dirs` takes the host's project directory name instead of hard-coding `.cox`. Hooks: `ShellHooks` (`sh -c`, JSON on stdin, exit 2 blocks, process-group kill on timeout, matcher regex), the `chain` rule, `HookChain` and the Claude verdict reader, with `HookEvent`, `HookOutcome`, `HookConfig`, `HooksConfig` and the `Hook` trait defined in the crate (cox-protocol's shapes, plus a schemars schema) and `with_context` moved from cox's `presence.rs`. Frontmatter is parsed with serde-saphyr 1.3.0 (serde_yaml is deprecated); untyped header fields (`allowed-tools`, `metadata`) are read as `serde_json::Value`, and non-string `metadata` values still render as the same YAML text serde_yaml gave (pinned in `tests/skills.rs`; `frontmatter::names` takes a `serde_json::Value`). No behaviour change otherwise; the cox skills and hooks tests moved to `tests/` with their fixtures. Check: `cargo test -p agent-ext`, `cargo clippy -p agent-ext --all-targets -- -D warnings` green on Rust 1.99.
