# agent-host-config — completed tasks

### T1. Extract agent-host-config from rtok-agent-sdk

Moved `register_mcp`, `register_server`, `unregister_mcp`, `unregister_server`, `mcp_entry`, `write` and `write_atomic` out of `rtok-agent-sdk` (aulo T1.18), with neutral names: the caller passes the server name and command. Differences from rtok: the file is edited through `jsonc-parser`'s lossless syntax tree instead of a parsed `serde_json::Value`, so formatting, comments, key order and number spelling outside our entry survive byte-for-byte (rtok re-printed the whole file, sorting keys); comments and trailing commas are accepted; a root or server map of another shape is an error instead of being replaced; backups come from `file-backup` (`<name>.bak-<unix-seconds>` beside the file, no `_backup/` folder, no pruning). Not moved: hooks and other JSON helpers (`edit_json`, `object_at`, `array_at`), the ownership check, prompts and plugin/skill installers. A round-trip test registers and unregisters an entry in a hand-edited config and compares the file byte-for-byte. Check: `cargo test -p agent-host-config`, `cargo clippy -p agent-host-config --all-targets -- -D warnings`, `cargo fmt --all --check`.
