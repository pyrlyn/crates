# Ideas

- Multi-bindings: collect every entry of a protocol into an array (plugins, hooks).
- Lifecycle: `start()`/`stop()` hooks on singletons, run in dependency order by the container.
- A SwiftUI helper that puts a container's `@MainActor` models into the environment.
- Graph export from the plugin (DOT next to the build products).
- Assisted injection: `@Injectable` types with some runtime arguments (`make(id:)`).
